- (#684) — **Added:** Every instance serves a CLI install script at `/install.sh`, so `curl -fsSL <instance>/install.sh | sh` installs the `loupe` CLI on macOS and Linux, and `brew install ubermuda/tap/loupe` installs it with Homebrew.
- (#684) — **Changed:** Automatic CLI updates are off by default for a new install. Turn them on with `loupe update auto on`. A bridge that updates itself into this release writes `autoUpdate: true` once and keeps updating.
- (#684) — **Added:** The agents page shows "Update available" when a bridge has automatic updates off and a newer CLI release fits the server. A click on it shows the upgrade command.
- (#684) — **Added:** The Connect page shows the install step before `loupe login`.
