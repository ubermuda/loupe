- (#475) — **Added:** the server records a CLI bridge worker run at `POST /api/projects/{handle}/worker-runs`, keeps it for 180 days, and sweeps the rest every hour. A run holds the card as plain values, so a deleted card leaves its history intact, and a spawn failure stays distinct from a process that ran and failed. The `bridge.run_retention_days` feature flag sets the window. The CLI bridge does not send reports yet, and there is no page for them yet.
