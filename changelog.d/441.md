- (#441) — **Added:** API tokens gain an `agent` scope, and the account settings page now mints it instead of `site-review`.
- (#441) — **Changed:** the loupe CLI reads `GET /api/agent/sites` and `GET /api/agent/stream`, which replace `GET /api/site-review/sites` and `GET /api/site-review/stream`.
- (#441) — **Changed:** an audit record written through an agent token reports the `agent` channel rather than `widget`.
- (#441) — **Security:** the firewall grants `^/api/agent` to the agent scope alone, so a project's widget token is refused before the controller runs.
- (#441) — **Removed:** an account-level API token minted before this release stops working on the CLI endpoints, and has to be minted again from `/account`. No stored scope is converted, because an unbound `site-review` token cannot be told apart from a widget token that sits in public page HTML. No widget token is affected, and no widget deployment changes.
