# Agent Document Review MCP — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a multi-tenant Symfony service where an agent submits a Markdown document via MCP, a human reviews it with inline anchored comments and a verdict, and the agent pulls the review back, revises, and resubmits — with comments re-anchored across versions.

**Architecture:** A single Symfony app exposing two surfaces over one domain: an MCP HTTP endpoint (`symfony/mcp-bundle`, tools authenticated by per-user PAT) and a server-rendered web reviewer UI. Every MCP tool is a thin adapter that dispatches a command/query and returns its result — the same command/query the web UI uses — so a REST API/CLI can be added later without touching business logic. Feedback delivery is human-activated pull: the reviewer submits in the UI, tells the agent, and the agent calls `get_review`.

**Tech Stack:** Symfony 8 / PHP 8.5 (bootstrapped from `~/Code/symfony-skeleton`), Doctrine ORM (UUID ids), `symfony/mcp-bundle` + `mcp/sdk`, `league/commonmark`, `symfony/html-sanitizer`, Twig + Stimulus + Tailwind, PHPUnit, Playwright.

## Conventions (inherited from the skeleton — follow exactly)

The repo is bootstrapped from `~/Code/symfony-skeleton`, which ships project skills under `.claude/skills/`. **Before writing code in an area, invoke the matching skill** — it holds the project-specific conventions:

- `project-testing` — PHPUnit unit/integration/WebTestCase

**Skeleton patterns this plan relies on (verbatim from the template):**

- **Entity ids are UUID**, generated by Doctrine, not the constructor:
  ```php

<?php
// src/Module/Account/Entity/ApiToken.php
namespace App\Module\Account\Entity;

use App\Module\Account\Repository\ApiTokenRepository;
use Doctrine\ORM\Mapping as ORM;
use Symfony\Bridge\Doctrine\Types\UuidType;
use Symfony\Component\Uid\Uuid;

#[ORM\Entity(repositoryClass: ApiTokenRepository::class)]
#[ORM\Table(name: 'api_tokens')]
class ApiToken
{
    #[ORM\Column(type: UuidType::NAME, unique: true)]
    #[ORM\CustomIdGenerator(class: 'doctrine.uuid_generator')]
    #[ORM\GeneratedValue(strategy: 'CUSTOM')]
    #[ORM\Id]
    public private(set) ?Uuid $id = null;

    private function __construct(
        #[ORM\ManyToOne(targetEntity: User::class)]
        #[ORM\JoinColumn(nullable: false)]
        public readonly User $owner,
        #[ORM\Column(length: 100)]
        public string $label,
        #[ORM\Column(length: 64, unique: true)]
        public private(set) string $tokenHash,
        #[ORM\Column]
        public readonly \DateTimeImmutable $createdAt = new \DateTimeImmutable(),
    ) {
    }

    /** @return array{0: self, 1: non-empty-string} */
    public static function issue(User $owner, string $label): array
    {
        $raw = bin2hex(random_bytes(32));

        return [new self($owner, $label, hash('sha256', $raw)), $raw];
    }

    public function matches(string $rawToken): bool
    {
        return hash_equals($this->tokenHash, hash('sha256', $rawToken));
    }
}
```

```php
<?php
// src/Module/Account/Security/ApiTokenAuthenticator.php
namespace App\Module\Account\Security;

use App\Module\Account\Repository\ApiTokenRepository;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Security\Core\Exception\AuthenticationException;
use Symfony\Component\Security\Http\Authenticator\AbstractAuthenticator;
use Symfony\Component\Security\Http\Authenticator\Passport\Badge\UserBadge;
use Symfony\Component\Security\Http\Authenticator\Passport\Passport;
use Symfony\Component\Security\Http\Authenticator\Passport\SelfValidatingPassport;
use Symfony\Component\Security\Core\Authentication\Token\TokenInterface;

final class ApiTokenAuthenticator extends AbstractAuthenticator
{
    public function __construct(private readonly ApiTokenRepository $tokens)
    {
    }

    public function supports(Request $request): ?bool
    {
        return str_starts_with((string) $request->headers->get('Authorization', ''), 'Bearer ');
    }

    public function authenticate(Request $request): Passport
    {
        $raw = substr((string) $request->headers->get('Authorization'), 7);
        $token = $this->tokens->findOneByRawToken($raw);
        if (null === $token) {
            throw new AuthenticationException('Invalid API token.');
        }

        return new SelfValidatingPassport(new UserBadge($token->owner->getUserIdentifier(), fn () => $token->owner));
    }

    public function onAuthenticationFailure(Request $request, AuthenticationException $exception): ?Response
    {
        return new Response('{"error":"unauthorized"}', 401, ['Content-Type' => 'application/json']);
    }

    public function onAuthenticationSuccess(Request $request, TokenInterface $token, string $firewallName): ?Response
    {
        return null;
    }
}
```

```php
// src/Module/Review/Service/MarkdownRenderer.php
namespace App\Module\Review\Service;

use League\CommonMark\CommonMarkConverter;
use Symfony\Component\HtmlSanitizer\HtmlSanitizer;
use Symfony\Component\HtmlSanitizer\HtmlSanitizerConfig;

final class MarkdownRenderer
{
    private readonly CommonMarkConverter $converter;
    private readonly HtmlSanitizer $sanitizer;

    public function __construct()
    {
        $this->converter = new CommonMarkConverter(['html_input' => 'escape', 'allow_unsafe_links' => false]);
        $config = (new HtmlSanitizerConfig())
            ->allowSafeElements()
            ->allowElement('h1')->allowElement('h2')->allowElement('h3')
            ->allowElement('h4')->allowElement('h5')->allowElement('h6')
            ->allowElement('ul')->allowElement('ol')->allowElement('li')
            ->allowElement('p')->allowElement('pre')->allowElement('code')
            ->allowElement('blockquote')->allowElement('strong')->allowElement('em')
            ->allowElement('a', ['href'])->allowElement('hr')
            ->allowElement('table')->allowElement('thead')->allowElement('tbody')
            ->allowElement('tr')->allowElement('th')->allowElement('td');
        $this->sanitizer = new HtmlSanitizer($config);
    }

    public function render(string $markdown): string
    {
        return $this->sanitizer->sanitize($this->converter->convert($markdown)->getContent());
    }
}
```

```php
    public function __construct(
```

```php
    {
        $version = new DocumentVersion($this, $this->versions->count() + 1, $markdown, $renderedHtml);
        $this->versions->add($version);

        return $version;
    }

    public function currentVersion(): DocumentVersion
    {
        return $this->versions->last() ?: throw new \LogicException('Document has no versions.');
    }
}
```

- [ ] **Step 4: Implement the service.** Capture context with `mb_substr`; resolve by scanning all occurrences of `quote` and choosing the one whose start is closest to `offsetHint` (ties → earliest). Use prefix/suffix to disambiguate when multiple occurrences are equidistant.

```php
<?php
// src/Module/Review/Service/AnchorService.php
namespace App\Module\Review\Service;

use App\Module\Review\ValueObject\Anchor;

final class AnchorService
{
    private const CONTEXT = 32;

    public function create(string $text, int $start, int $length): Anchor
    {
        $quote = substr($text, $start, $length);
        $prefix = substr($text, max(0, $start - self::CONTEXT), min(self::CONTEXT, $start));
        $suffix = substr($text, $start + $length, self::CONTEXT);

        return new Anchor($quote, $prefix, $suffix, $start);
    }

    public function resolve(string $text, Anchor $anchor): ?int
    {
        if ('' === $anchor->quote) {
            return null;
        }

        $offsets = [];
        $from = 0;
        while (false !== ($pos = strpos($text, $anchor->quote, $from))) {
            $offsets[] = $pos;
            $from = $pos + 1;
        }
        if ([] === $offsets) {
            return null;
        }

        usort($offsets, function (int $a, int $b) use ($anchor, $text): int {
            $score = fn (int $o): int => abs($o - $anchor->offsetHint)
                - ($this->contextScore($text, $o, $anchor) * self::CONTEXT);

            return $score($a) <=> $score($b);
        });

        return $offsets[0];
    }

    private function contextScore(string $text, int $offset, Anchor $anchor): int
    {
        $before = substr($text, max(0, $offset - self::CONTEXT), min(self::CONTEXT, $offset));
        $after = substr($text, $offset + strlen($anchor->quote), self::CONTEXT);
        $score = 0;
        if ('' !== $anchor->prefix && str_ends_with($before, substr($anchor->prefix, -8))) {
            ++$score;
        }
        if ('' !== $anchor->suffix && str_starts_with($after, substr($anchor->suffix, 0, 8))) {
            ++$score;
        }

        return $score;
    }
}
```
